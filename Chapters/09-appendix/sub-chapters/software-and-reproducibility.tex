\section{Software artifacts and reproducibility}
\label{appendix:software-and-reproducibility}

%Academic rewrite
The software supporting this study is organized as three repositories under the \texttt{kartAI} organization, run as a pipeline. \texttt{doppa-data-contribution} (\url{https://github.com/kartAI/doppa-data-contribution}) downloads the public source datasets, normalizes them to a shared GeoParquet schema, and publishes them to Blob Storage. \texttt{doppa} (\url{https://github.com/kartAI/doppa}) reads those datasets and runs the benchmarks, writing the per-iteration results back to Blob Storage. \texttt{doppa-analytics} (\url{https://github.com/kartAI/doppa-analytics}) reads those results and generates the figures and tables reported in this thesis. Each repository's README documents its setup and the commands to run it.

%Academic rewrite
The reported figures and tables are regenerated by \texttt{doppa-analytics} from the result data that \texttt{doppa} writes, then copied into the thesis source. The version of each repository used is pinned by commit: \texttt{doppa-data-contribution} at \texttt{6bea50e}, \texttt{doppa} at \texttt{a06e9fd}, and \texttt{doppa-analytics} at \texttt{30f1e39}. The full steps to reproduce the results from these commits are given in the repositories' READMEs.
