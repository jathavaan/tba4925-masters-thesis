\section{Project description}
\begin{itemize}
    \item How do cloud-native formats (GeoParquet, PMTiles) compare to traditional formats and engines (Shapefile, PostGIS, WMS-based vector tiles) in read performance, network transfer, and operational cost across analytical and visualisation spatial workloads served from Azure?
    \item How do read performance, network transfer, and operational cost change when distributed cloud-native engines (Apache Sedona on Databricks) scale horizontally, compared to single-node engines (PostGIS, DuckDB) on the same workloads?
\end{itemize}
