\section{Architecture overview}
The research questions require the system to compare spatial query performance across configurations that differ in storage format, processing engine, and execution model. To produce valid comparisons, the system isolates the variable under test while holding everything else constant. Every architectural decision traces back to enabling a fair answer to one of the three research questions.
