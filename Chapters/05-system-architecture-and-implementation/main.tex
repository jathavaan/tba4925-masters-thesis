The experimental design in Chapter~\ref{ch:methodology} fixes what is varied, what is held constant, and how each outcome is measured; this chapter realizes that design as a running system on Azure. Every architectural choice answers a single constraint: a difference in elapsed time, transferred bytes, or cost must trace to the configuration under test rather than to the surrounding infrastructure.
